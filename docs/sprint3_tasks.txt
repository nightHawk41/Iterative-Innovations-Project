----------------------
Current Sprint 3 Tasks
----------------------

Sprint 3 Goal:
Revamp the frontend to match the vending.html prototype: a persistent 6x4 machine
grid, sidebar with Dashboard/Admin tab switching, a slot purchase flow, admin panel
enhancements, and the new backend endpoints that support them.

Already Completed (no action needed):
  - Routing defaults: wildcard route redirects to /dashboard (App.js)
  - Dashboard stats header: Total Slots, Healthy, Low/Expiring, Critical (DashboardPage.js)
  - Transaction CSV file picker and POST /api/transactions/process call (TransactionUpload.js)

Implementation Order Note:
Backend tasks should be completed before the frontend tasks that depend on them.
Frontend tasks marked with [DEPENDS ON ...] must wait for the referenced backend task.
Resolve the architecture decision in Task A-1 before beginning any Phase 1 frontend work.

------------------------------------------------------------
ARCHITECTURE DECISION
------------------------------------------------------------

[TASK A-1] Migrate the app shell to the prototype's persistent two-column layout.
  Decision: adopt the prototype layout -- sidebar with Dashboard/Admin tab switching,
  machine grid always visible on the right, no page-level navigation.

  Required changes to the existing codebase:
    - App.js: remove React Router (<Routes>, <Route>, <Navigate>). Replace with a
      two-column shell: left sidebar (fixed width) + right machine panel (flex: 1).
      A single tab state value ("dashboard" | "admin") controls which sidebar content
      is visible; the machine grid renders unconditionally in the right panel.
    - Sidebar.js: remove NavLink-based navigation. Replace with two tab buttons
      (Dashboard / Admin) that toggle the sidebar content via the tab state.
    - DashboardPage.js: dissolve this page component. Move its stats header and
      AlertsBanner into the Dashboard tab content area of the sidebar.
    - AdminPage.js: dissolve this page component. Move its admin controls
      (restock, CSV uploads, sales report) into the Admin tab content area.
      The InventoryGrid inside AdminPage is removed; the grid is now the shared
      right panel and does not belong to either tab.
    - Remove react-router-dom from the project if no other code uses it after
      the migration, and remove the corresponding import in index.js.

------------------------------------------------------------
FRONTEND: Phase 1 -- Vending Machine Grid
------------------------------------------------------------

[TASK F-1] Replace the Accordion layout in InventoryGrid.js with a static 6x4 CSS grid.
  The grid must span rows A-F and columns 1-4, producing exactly 24 slot cells.
  Remove the existing Accordion, groupByRow logic, Expand All / Collapse All buttons,
  and the react-bootstrap Accordion import.
  Render all 24 SlotCard components directly in the grid without any row grouping.

[TASK F-2] Update SlotCard to match the vending machine slot display.
  Each slot must show: position label (e.g., "A1"), product name, price, stock count,
  and expiration countdown ("Exp: Nd" or "Expired" if days_until_expiry < 0).
  Remove the existing StatusIndicator badge and left-border color styling.
  Apply background color directly to the slot cell based on status (see Task F-3).

[TASK F-3] Implement status color and disabled-state logic in SlotCard.
  Color rules (applied as the slot's background color):
    - Green  (#5db85d / white text):  stock > 5 AND days_until_expiry > 5
    - Yellow (#f5c518 / dark text):   stock <= 5 OR days_until_expiry <= 5
    - Red    (#e53935 / white text):  stock <= 2 OR days_until_expiry <= 2
    - Gray   (#aaa, disabled):        stock === 0 OR days_until_expiry < 0 (expired)
  Confirm whether the backend's status_color field already matches these exact thresholds.
  If thresholds differ, decide whether to use the backend value or recalculate on the frontend.
  Disabled slots must not respond to clicks and must render at reduced opacity.

[TASK F-4] Make non-disabled slots interactive: clicking opens a purchase confirmation modal.
  The modal must display the item name, slot position (e.g., "A1"), and price.
  Modal prompt format: "Purchase [item name] (Slot [position]) for $[price]?"
  Use a React modal overlay (not window.confirm()) with Confirm and Cancel buttons.
  Purchase interaction is only active when the Dashboard tab is selected.
  When the Admin tab is active, all slots must be non-clickable (pointer-events: none
  or equivalent) even if they are not otherwise disabled.
  [DEPENDS ON B-1]

[TASK F-5] Implement purchase confirmation logic wired to the backend.
  On confirm: send POST /api/purchase with { "slot_id": "<id>", "quantity": 1 }.
  On success: decrement the displayed stock for that slot and re-render the grid.
  On failure (e.g., out of stock): close the modal and show an error toast.
  On cancel: close the modal without any changes.
  This flow must never be reachable from the Admin tab (enforced by Task F-4).
  [DEPENDS ON B-1]

------------------------------------------------------------
FRONTEND: Phase 2 -- Dashboard & Navigation
------------------------------------------------------------

[TASK F-6] Add Reload and Help global control buttons to the UI.
  Reload behavior — choose one before implementing:
    Option A (re-fetch only): re-call GET /api/inventory and refresh the grid.
                              No confirmation prompt or backend reset needed.
    Option B (full reset):    show a confirmation prompt, then call POST /api/reset
                              to restore default machine state, then re-fetch the grid.
                              Requires Task B-4.
  Help button: show a toast or info modal with brief usage instructions
               (e.g., "Click a slot to purchase. Use Admin Panel to restock.").

------------------------------------------------------------
FRONTEND: Phase 3 -- Admin Panel Enhancements
------------------------------------------------------------

[TASK F-7] Refine the Manual Restock Form in RestockModal.js.
  The file picker, field validation, and cancel/clear behavior are already implemented.
  Add: a live "X days until expiry" preview that recalculates as the expiration date changes.
  Add: display a success toast notification after a successful restock submission,
       replacing or supplementing the current inline feedback message.

[TASK F-8] Update Transaction CSV upload to show a toast on success.
  The file picker, .csv validation, and POST /api/transactions/process call already exist.
  Replace the current inline result panel with a toast notification on successful upload.
  Keep the existing inline error display for failure cases.

[TASK F-9] Implement the "Upload New Inventory" panel in the Admin view.
  Add a new collapsible panel styled consistently with the existing TransactionUpload section.
  Include: a file picker that restricts to .csv files and an "Upload & Process" button.
  On submit: POST the file to POST /api/inventory/upload.
  On success: show a success toast and refresh the inventory grid.
  On failure: display an inline error message below the picker.
  [DEPENDS ON B-2]

[TASK F-10] Build the Sales Report flow in the Admin view.
  Add a "Generate Sales Report" button.
  On click: show a confirmation modal asking the user to confirm or cancel.
  On confirm: call GET /api/sales-report and trigger a file download of the response.
  On success: show a toast ("Sales report generated.").
  On failure: show an error toast with the reason.
  [DEPENDS ON B-3]

------------------------------------------------------------
BACKEND: Phase 4 -- New Endpoints
------------------------------------------------------------

[TASK B-1] Implement POST /api/purchase (api/inventory_routes.py).
  Request body (JSON): { "slot_id": "A1", "quantity": 1 }.
  Behavior: look up the slot, confirm stock > 0, decrement by quantity, persist, return updated slot.
  On success (200): return updated slot dict + { "message": "Purchase successful" }.
  On out-of-stock or concurrent write conflict (409): return a ConcurrencyError-style response
    consistent with the existing D-2 pattern used in restock and transaction routes.
  On unknown slot_id (400): return a descriptive error message.
  This endpoint is a hard dependency for frontend Tasks F-4 and F-5.

[TASK B-2] Implement POST /api/inventory/upload (api/inventory_routes.py).
  Accepts a CSV file upload (multipart/form-data, field name = "file").
  Expected CSV columns must match the schema of the existing inventory_config.csv.
  Behavior: parse the uploaded CSV, clear all existing ItemSlot rows, seed with new rows.
  On success (200): return { "message": "Inventory uploaded", "slot_count": <int> }.
  On bad file format or parse error (400): return a descriptive error without touching the database.

[TASK B-3] Implement GET /api/sales-report (api/transaction_routes.py).
  Aggregate data from the most recently processed transaction stream to produce a sales report.
  Report columns: slot_id, item_name, total_units_sold, total_revenue.
  Return the report as a downloadable CSV file with header:
    Content-Disposition: attachment; filename="sales_report.csv"
  If no transactions have been processed yet, return 404 with a descriptive message.

[TASK B-4] Implement POST /api/reset (api/inventory_routes.py).  [CONDITIONAL -- see Task F-6]
  Re-run the seed script to restore the database to its original default state.
  On success (200): return { "message": "Machine reset to default state" }.
  Only implement this task if the Reload button in Task F-6 is implemented as Option B
  (full machine reset). If Option A (re-fetch only) is chosen, this task is not needed.

    ["Candy",1.00],["Milk",2.25],["Smoothie",3.50],["Water Bottle",1.50]
];

const rows = ["A","B","C","D","E","F"];

let inventory = Array.from({length:24}, () => Math.floor(Math.random()*11));
let daysUntilExpiration = Array.from({length:24}, () => Math.floor(Math.random()*13)-2);
let selectedIndex = null;

// ── Slot ID helpers ──
function slotLabel(i) {
    return rows[Math.floor(i/4)] + i%4;
}

// ── Color ──
function getColorClass(count, days) {
    if (days < 0 || count === 0) return "disabled";
    if (count <= 2 || days <= 2) return "red";
    if (count <= 5 || days <= 5) return "yellow";
    return "green";
}

// ── Render machine ──
function renderMachine() {
    const machine = document.getElementById("machine");
    machine.innerHTML = "";
    for (let i=0; i<24; i++) {
        const [name, price] = items[i];
        const count = inventory[i];
        const days = daysUntilExpiration[i];
        const expired = days < 0;
        const colorClass = getColorClass(count, days);

        const slot = document.createElement("div");
        slot.className = `slot ${colorClass}`;

        slot.innerHTML = `
            <div class="slot-id">${slotLabel(i)}</div>
            <div class="slot-name">${name}</div>
            <div class="slot-price">$${price.toFixed(2)}</div>
            <div class="slot-stock">Stock: ${count}</div>
            <div class="slot-exp">${expired ? "⚠ Expired" : `Exp: ${days}d`}</div>
        `;

        if (count > 0 && !expired) {
            slot.onclick = () => openPopup(i, slotLabel(i), name, price);
        }

        machine.appendChild(slot);
    }
    updateStats();
}

// ── Stats ──
function updateStats() {
    let healthy=0, warning=0, critical=0;
    for (let i=0; i<24; i++) {
        const c = inventory[i], d = daysUntilExpiration[i];
        if (d < 0 || c === 0) critical++;
        else if (c < 3 || d <= 2) warning++;
        else healthy++;
    }
	
    document.getElementById("sb-healthy").textContent = healthy;
    document.getElementById("sb-warning").textContent = warning;
    document.getElementById("sb-critical").textContent = critical;

    // populate restock slot dropdown
    const sel = document.getElementById("restock-slot");
    sel.innerHTML = '<option value="">– Select Slot –</option>';
    for (let i=0; i<24; i++) {
        const opt = document.createElement("option");
        opt.value = i;
        opt.textContent = `${slotLabel(i)} – ${items[i][0]}`;
        sel.appendChild(opt);
    }
}

// ── Popup ──
function openPopup(index, slotId, name, price) {
    selectedIndex = index;
    document.getElementById("popup-text").textContent =
        `Purchase ${name} (Slot ${slotId}) for $${price.toFixed(2)}?`;
    document.getElementById("popup").style.display = "flex";
}

function closePopup() {
    document.getElementById("popup").style.display = "none";
}

function confirmPurchase() {
    if (selectedIndex !== null && inventory[selectedIndex] > 0) {
        inventory[selectedIndex]--;
        showToast(`✓ ${items[selectedIndex][0]} dispensed!`);
    }
    closePopup();
    renderMachine();
}

// ── Sidebar tab switch ──
function switchSidebarTab(tab, btn) {
    document.querySelectorAll(".nav-tab").forEach(t => t.classList.remove("active"));
    btn.classList.add("active");
    document.getElementById("sidebar-dashboard").style.display = tab === "dashboard" ? "block" : "none";
    document.getElementById("sidebar-admin").style.display = tab === "admin" ? "block" : "none";
}

// ── Collapsible panels ──
function togglePanel(bodyId, header) {
    const body = document.getElementById(bodyId);
    const isOpen = body.classList.toggle("open");
    header.querySelector(".toggle-btn").textContent = isOpen ? "▾" : "▸";
}

// ── Restock ──
function doRestock() {
    const idx = document.getElementById("restock-slot").value;
    const qty = parseInt(document.getElementById("restock-qty").value);
    const dateVal = document.getElementById("restock-date").value;

    if (idx === "" || isNaN(qty) || qty < 1) {
        showToast("⚠ Please fill in all restock fields.");
        return;
    }

    inventory[parseInt(idx)] = Math.min(10, inventory[parseInt(idx)] + qty);

    if (dateVal) {
        const today = new Date();
        const exp = new Date(dateVal);
        const diff = Math.round((exp - today) / (1000*60*60*24));
        daysUntilExpiration[parseInt(idx)] = diff;
    }

    showToast(`✓ ${items[parseInt(idx)][0]} restocked (+${qty})`);
    clearRestock();
    renderMachine();
}

function clearRestock() {
    document.getElementById("restock-slot").value = "";
    document.getElementById("restock-qty").value = "";
    document.getElementById("restock-date").value = "";
}

// ── Toast ──
function showToast(msg) {
    const t = document.getElementById("toast");
    t.textContent = msg;
    t.classList.add("show");
    setTimeout(() => t.classList.remove("show"), 3000);
}
