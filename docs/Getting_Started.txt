# Iterative Innovations - Vending Inventory System

This is a Full-Stack application using **Flask** (Backend) and **React** (Frontend).

## Getting Started

To ensure a consistent development experience, we recommend using **WSL (Windows Subsystem for Linux)** 
on Windows machines. Standardizing our environment prevents issues with pathing and package management.

Follow these steps to get the project running on your local machine (WSL/Linux/macOS/Windows). 

---

### 1. Prerequisites
Ensure you have the following installed:
* Python 3.10+
* Node.js & npm     (Standard LTS version)
* VS Code           (Recommended with 'WSL' and 'Python' extensions)

---

### 2. Backend Setup (Flask)
1. Navigate to the backend folder:
   ```bash
   cd backend
   ```

2. Create a virtual environment:
    - WSL/Linux/macOS:
   ```bash
   python3 -m venv .venv
    ```
   - Windows (Cmd/PowerShell):
    ```cmd
    python -m venv .venv
    ```

3. Activate the virtual environment:
    - WSL/Linux/macOS:
    ```bash
    source .venv/bin/activate
    ```
    - Windows (Command Prompt):
    ```cmd
    .venv\Scripts\activate
    ```
    - Windows (PowerShell):
    ```powershell
    .venv\Scripts\Activate.ps1
    ```

4. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

5. Start the Flask server:
    ```bash
    python3 app/server.py
    ```
    The backend will run on http://localhost:5000 by default. You need to append `/test` 
    to access the API endpoints (e.g., http://localhost:5000/test).

### 3. Frontend Setup (React)
1. Open a new terminal and navigate to the frontend folder:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the React development server:
   ```bash
   npm start
   ```

    The frontend will run on http://localhost:3000 by default.
